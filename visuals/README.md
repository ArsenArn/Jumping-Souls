# Визуалы персонажей

Поместите JPG-картинку с названием персонажа в одноимённую подпапку — игра подхватит её и автоматически ужмёт до размера персонажа.

Доступные папки:
- `visuals/player/player.jpg`
- `visuals/enemy/enemy.jpg`
- `visuals/enemy_fast/enemy_fast.jpg`
- `visuals/enemy_large/enemy_large.jpg`
- `visuals/enemy_blue/enemy_blue.jpg`
- `visuals/enemy_flying/enemy_flying.jpg`

Если в подпапке нет нужной картинки, персонаж будет отрисован базовым способом.
